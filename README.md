# Robótica

Cómo un robot sabe dónde está y decide cómo moverse: posiciones y giros, cinemática directa e inversa, dinámica, control PID, filtros de Kalman y de partículas, SLAM, planificación de movimiento y ROS.

**Ver en línea:** https://aaramirez.github.io/robotica/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
